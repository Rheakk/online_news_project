# Experiment 3 — Headline Morphing & News Selection

This repository contains the analysis code for **Experiment 3** of an online news consumption study examining how AI-generated linguistic cues embedded in headlines influence readers' selection behavior and credibility perceptions.

---

## Research Overview

Participants browsed a simulated news feed containing 18 headlines and selected those they wanted to read ("add to cart"). Each headline existed in one of three versions — **credibility-boosted**, **engagement-boosted**, or **neutral** — generated by morphing the original headline text using targeted linguistic cues. Participants were randomly assigned to one of two instruction conditions:

- **Accuracy condition** — instructed to select headlines they found credible and accurate
- **Engagement condition** — instructed to select headlines they found interesting and engaging

The experiment tests whether readers respond to headline morphs in alignment with their stated goal (i.e., does the credibility morph raise perceived credibility? does the engagement morph raise selection rates under engagement instructions?), and whether instruction framing moderates these effects.

## Scripts

### `cleaning___visualizations.ipynb` — Python

Processes the raw Qualtrics export and produces all descriptive figures.

**Pipeline:**

| Section | Steps | Description |
|---|---|---|
| 1 | 0–5 | Load raw CSV, drop Qualtrics header rows, resolve duplicate column names, clean Prolific IDs, apply four attention checks |
| 2 | 6 | Rename demographic columns from Qualtrics codes (Q1–Q20) to readable labels |
| 3 | 7 | Reshape from participant-level to trial-level (one row per participant × headline) |
| 4 | 8–9 | Create analysis variables: `Selected`, `Instruction`, `MorphCredibility`, `MorphEngagement`, cue type, headline IDs |
| 5 | — | Summary tables and three visualizations |

**Outputs:**
- `analysis_df.csv` — trial-level dataframe consumed by the R modeling script
- `plot1_dimension_selection.png` — P(selected) by instruction × headline dimension
- `plot2_cue_selection.png` — P(selected) by instruction × specific cue type
- `scatter_selection_vs_credibility.png` — selection rate vs. average credibility rating per cue type

---

### `experiment3_modeling.R` — R

Fits two pre-registered mixed-effects regression models and renders publication-ready tables.

**Model 1 — Headline Selection (Binary DV)**
- `glmer` (binomial logit) predicting whether a participant selected a headline
- Fixed effects: `MorphCredibility`, `MorphEngagement`, `Instruction`, and their two-way interactions
- Random effects: by-participant and by-headline intercepts
- Optimizer: `bobyqa` (increased iterations for convergence)

**Model 2 — Perceived Credibility (Continuous DV)**
- `lmer` (REML) predicting participant credibility ratings (1–7 scale)
- Identical fixed- and random-effect structure to Model 1
- P-values via Satterthwaite approximation (`lmerTest`)

Both models output PNAS-style formatted tables via `kableExtra` with significance stars and footnotes.

## Key Variables

| Variable | Type | Description |
|---|---|---|
| `Selected` | Binary (0/1) | Whether participant added headline to cart |
| `credibility_rating` | Continuous (1–7) | Perceived credibility rating for each headline |
| `MorphCredibility` | Dummy | 1 = credibility-boosted headline, 0 = otherwise |
| `MorphEngagement` | Dummy | 1 = engagement-boosted headline, 0 = otherwise |
| `Instruction` | Dummy | 0 = accuracy instruction, 1 = engagement instruction |
| `cue_no` | Categorical | Specific cue applied: C1–C3 (credibility), E1–E3 (engagement), N (neutral) |
| `PROLIFIC_PID` | ID | Participant identifier (random effect grouping) |
| `GOID` | ID | Headline identifier (random effect grouping) |

### Headline Cue Types

| Code | Family | Description |
|---|---|---|
| C1 | Credibility | Clarity and precision |
| C2 | Credibility | Restrained / neutral tone |
| C3 | Credibility | Institutional framing |
| E1 | Engagement | Novelty / unexpected framing |
| E2 | Engagement | Emotional salience |
| E3 | Engagement | Narrative tension |
| N  | Neutral | No cue applied |

## Notes on Attention Checks

Four embedded attention checks were applied during cleaning. Participants were excluded if they failed any of them:

1. **Q11** — must select response option `2`
2. **Q15** — must select response option `2`
3. **Q2** — cart selections must include item `19` (a designated check headline)
4. **Cred_19** — credibility rating for item 19 must equal `4`
